health-weight-sync

A personal tool. Not a public service.

health-weight-sync is a small personal script, used only by its owner. Once an hour it reads the owner's own body weight and body fat percentage from the Google Health API (read-only) and writes them to a Google Sheet in the owner's own Google account, so the owner can track a diet.

There is no sign-up, no other users, and no data is shared with anyone.

日本語

health-weight-sync は、作成者本人だけが使う個人用のスクリプトです。 1時間ごとに、本人の体重と体脂肪率を Google Health API から読み取り（読み取り専用）、 本人の Google アカウント内のスプレッドシートに記録します。 一般向けのサービスではなく、第三者へのデータ提供は一切ありません。
