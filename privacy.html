Privacy Policy

health-weight-sync — last updated 2026-11-12

health-weight-sync is a personal script operated by an individual for their own use only. The only user is the owner.

Data accessed

With the owner's consent, the script uses the Google Health API scope googlehealth.health_metrics_and_measurements.readonly to read the owner's body weight and body fat percentage. It does not read any other data, and it never writes to or deletes data in Google Health.

How the data is used and stored

The values are written to a Google Sheet in the owner's own Google account and are used only to track the owner's weight. OAuth tokens are stored in the script's private properties in the owner's Google Apps Script project. Nothing is stored on any other server.

Sharing

No data is sold, shared with, or transferred to any third party, and it is not used for advertising.

Limited Use

health-weight-sync's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account > Third-party apps & services.

Contact

Please open an issue in this site's GitHub repository.
